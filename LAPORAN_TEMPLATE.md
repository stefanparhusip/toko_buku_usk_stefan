## 1. Deskripsi Aplikasi
3bieStore App adalah aplikasi web toko buku berbasis Laravel yang menyediakan fitur manajemen buku untuk admin dan fitur transaksi pembelian untuk user. Aplikasi ini menerapkan autentikasi, otorisasi berbasis role, cart, checkout, dan monitoring order.

## 2. Fitur Aplikasi
### 2.1 Fitur Authentication
- Register user
- Login user
- Logout

### 2.2 Fitur Role
- Role `admin` dan `user`
- Pembatasan akses route menggunakan middleware

### 2.3 Fitur Admin
- Dashboard monitoring
- CRUD Category
- CRUD Book (upload image)
- Monitoring Orders

### 2.4 Fitur User
- Melihat daftar buku (pagination)
- Melihat detail buku
- Search buku berdasarkan judul/kategori
- Cart (add/update/delete)
- Checkout COD
- Riwayat order
